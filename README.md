## 📋 Descripción

**Gitfu** es un sistema embebido diseñado para la evaluación y análisis de cuentas de GitHub. La aplicación se basa en el ecosistema de **Gitfu.com** y su sistema de cards, integrando el consumo directo de la **API de GitHub** para obtener datos en tiempo real sobre los perfiles de desarrolladores.

El objetivo principal es proporcionar una interfaz visual e intuitiva que permita evaluar métricas clave de cualquier cuenta de GitHub mediante tarjetas interactivas.

## ✨ Características

- 🔗 **Integración con API de GitHub**: Consumo dinámico de datos de perfiles públicos.
- 🃏 **Sistema de Cards**: Visualización modular y atractiva de la información del usuario.
- ⚡ **Ligero y Rápido**: Construido con tecnologías web nativas para máxima compatibilidad.
- 🌐 **Interfaz Intuitiva**: Diseño enfocado en la experiencia del usuario (UX).
